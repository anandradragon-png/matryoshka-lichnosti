# PROJECT_MAP — Матрёшка Личности (prototype)

Статический прототип. Ванильный JS, ES-модули, без сборщика.
Данные — localStorage. Деплой — GitHub Pages из этой папки.

Серверная часть написана и развёрнута, но **выключена**: в `index.html`
`window.ML_API_URL = ''`. Пока пусто — приложение работает целиком в браузере,
как раньше. Код сервера лежит вне этого репозитория, в
`Матрешка личности/сервер-данных/` (Yandex Cloud Function + YDB).
Включать только после уведомления Роскомнадзора: дневник эмоций — специальная
категория персональных данных (ст. 10 152-ФЗ).

## Ключи localStorage (все через `ML_KEYS` в `js/core.js`)

| Ключ | Что хранит |
|---|---|
| `ml_diary__<логин>` | Записи дневника эмоций конкретного человека (без входа — `ml_diary`) |
| `ml_users` | Список пользователей |
| `ml_session` | Логин текущего пользователя |
| `ml_promos` | Промо-коды |
| `ml_feedback` | Отзывы |
| `ml_cookie_consent` | Согласие с cookie |
| `ml_companies` | B2B-компании |
| `ml_journal__<логин>` | Журнал дня конкретного человека (без входа — `ml_journal`) |
| `ml_plan` | Тариф пользователей (`{ login: plan }`) |
| `ml_token` | Пропуск на сервер текущего человека (живёт 30 дней). Пусто — работаем только в браузере |
| `ml_synced` | Кто уже отдал серверу накопленное в браузере (`{ login: true }`), чтобы не отправлять дважды |
| `ml_pending` | Очередь недоехавшего: связь оборвалась — записи ждут здесь и уходят при следующем входе |
| `ml_emotest__<логин>` | Ответы и результат теста чувств конкретного человека (без входа — `ml_emotest`) |

## Куда класть новый файл

| Что за файл | Куда |
|---|---|
| Новая секция сайта (логика) | `js/<имя-секции>.js` + строка в `js/main.js` |
| Логика, которой пользуются два и более модуля | отдельный модуль с именем-существительным, не в `util.js` |
| Новый раздел отчёта | свой файл `js/report/section-<имя>.js` с функцией `(ctx, depth)` + строка в `bodyHtml` в `document.js`; данные — в `js/report/data.js` |
| Стили отчёта | `report.css` (префикс `r-`), НЕ в `styles.css` |
| Стили приложения | `styles.css`, класс с префиксом своей секции. Секция крупнее сотни строк — своя таблица рядом, как `emotest.css`: `styles.css` уже выше предела |
| Новый тест-опросник | три файла: данные, подсчёт без DOM, разметка. Экран — четвёртым. Смешивать подсчёт с разметкой нельзя: ошибка в подсчёте тише всего и дороже всего |
| Юридический документ | `docs/` + отдельная галочка согласия в регистрации |
| Тест | `test/<модуль>.test.js` |

Оба адреса обновляются автоматически из `main`: GitHub Pages — сам,
домен — через `.github/workflows/deploy.yml` (заливает в бакет, сбрасывает
кэш CDN и сверяет, что домен отдаёт тот же `index.html`, что в репозитории).
Выкатка на домен идёт только после зелёного CI.

Доступ к бакету — сервисный аккаунт `github-deploy-matreshka` (облако yuplab),
ключи в секретах репозитория `YC_S3_KEY_ID`, `YC_S3_SECRET`, `YC_SA_KEY`.

Заголовок `Cache-Host: yccdn-defra01fr5-*` в ответе домена означает лишь, что
Yandex CDN выбрал узел по расположению посетителя (для Тбилиси — Франкфурт).
Сам сайт лежит в российском хранилище, `213.180.193.247`.

## Известные ограничения

| Что | Состояние |
|---|---|
| `index.html` 665 строк, `styles.css` 781 | Выше нормы. Разбиение требует сборщика, которого в проекте намеренно нет |
| Тексты теста чувств не вычитаны | 40 утверждений и 16 профилей отправлены Альбине на вычитку 13.09.2026 (docx через бот YupDar), ответа пока нет. Методика — своя эмотология (заметить → тело → разрешить → завершить), не переводной опросник |
| Экраны теста чувств не покрыты тестами | `emotest.js` и `emotest-view.js` проверены только руками в браузере. Подсчёт и данные покрыты |
| `js/organizer.js` 346 | Выше нормы 250, разбиение не согласовано |
| `js/practices-data.js` 360 | Файл данных, а не логики. Разбивать по категориям не надо: одна правка формата превратится в семь |
| Авторизация фейковая, **пока сервер выключен** | При `ML_API_URL = ''` пароли лежат в localStorage и в открытом исходнике. Привязка данных к логину (`scope.js`) разделяет людей, но не защищает. Включим сервер — пароли станут хешами на сервере (PBKDF2), вход по токену |
| Самочувствие в HR-панели | Синтетическое (`synthWb()` в `corp-store.js`), в интерфейсе помечено «пример». Дары — настоящий расчёт по датам рождения |
